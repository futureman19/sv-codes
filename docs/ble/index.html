TRY IT OVER REAL RADIO

Transmit from a second phone.

  1. On a second Android phone, install nRF Connect (free, Nordic Semiconductor).
  2. Open the Advertiser tab → new advertiser → add Manufacturer Specific Data: company ID 0xFFFF, data = one fragment hex below. Add all 9 as separate advertisers (chipset permitting) and enable them.
  3. Start scanning on this page. When the set completes, the signed command appears above.

WHAT YOU JUST SAW

One-way broadcast, zero handshake. The transmitter never learns who listened. The receiver never trusts the radio — it trusts the signature: the envelope is verified against the published test authority exactly as a robot would (BMP-0000 §4.3, L1: radio range is the physical-presence proof).

Spec: BMP-0001 — BMP-BLE. Reference codec: poc/svcode/ble.py + this page's docs/js/ble.js — two independent receivers, bit-identical results.
