The loop (SV-0002)

1 · Scan

Any camera decodes the matrix; the issuer's ECDSA signature verifies. This demonstration uses a publicly known issuer key, not a secure production identity.

2 · Reveal

The cert's item selects the generator, seed drives it, art pins the canonical render. Every honoring game renders it in its own style.

3 · Own

Ownership is the 1-satoshi ordinal at mint. Free claim = mint directly to the receiving address. Transfer = an ordinary ordinal send. No key ever changes hands.

The returned 221-byte certificate passed independent Python and JavaScript PNG/JPEG decoders. This is a broadcast/indexer-verified anchor, not a browser SPV proof.
