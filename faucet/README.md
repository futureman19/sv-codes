# sv-faucet

Sticker campaign faucet: pays a small BSV amount to fresh in-browser wallets
generated by the landing page (`docs/j/`).

- `POST /claim {pub, s, fp}` → `{address, sats, txid}` — rate-limited
  (1 per pubkey, per-IP / per-device daily caps, global daily cap)
- `GET /health` → network, funding address, balance, claim counts
- `GET /stats` → per-sticker claim/sats totals

Runs on fly.io (`fly.toml`, 1 GB volume for the SQLite claims DB).
Config via env/secrets: `FAUCET_WIF` (fly secret), `NETWORK` (main|test),
`FAUCET_SATS` (default 50000), `FEE_SATS`, `MAX_IP_PER_DAY`, `MAX_FP`,
`MAX_PER_DAY`, `DB_PATH`.

`txbuilder.py` constructs and signs raw P2PKH transactions
(SIGHASH_ALL|FORKID) with no dependencies — verified by `test_txbuilder.py`
(17 checks: hash/WIF/address vectors, sighash+signature self-consistency,
structural re-parse) and `test_sighash_vectors.py` (11 independent Bitcoin
ABC forkid consensus vectors, amount=0).

```sh
python test_txbuilder.py
SIGHASH_JSON=/path/to/sighash.json python test_sighash_vectors.py
```
